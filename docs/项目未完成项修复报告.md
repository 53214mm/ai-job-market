## 二、详细修复内容

### 1. 修复 AI 简历分析 Bug（严重）

**问题**：`ResumeServiceImpl.aiAnalyze()` 调用 AI 获取分析结果后，结果字符串被丢弃，所有评分字段存储为空。

**修复**：
- 引入 Jackson `ObjectMapper` 解析 AI 返回的 JSON
- 添加 `extractJson()` 方法从 AI 回复中提取 JSON
- 解析 `overallScore`、`formatScore`、`contentScore`、`keywordScore`、`strengths`、`weaknesses`、`suggestions` 并写入数据库
- 容错处理：JSON 解析失败时保存原始结果到 `suggestions` 字段

**涉及文件**：`src/main/java/.../service/impl/ResumeServiceImpl.java`

---

### 2. 通知集成到投递流程

**问题**：`ApplicationServiceImpl` 的状态变更和面试安排不会推送通知给求职者。

**修复**：
- 注入 `NotificationService`
- `updateStatus()` 中：状态变更后自动推送 `APPLICATION_UPDATE` 类型通知
- `scheduleInterview()` 中：安排面试后自动推送 `INTERVIEW_INVITE` 类型通知
- 通知内容包含职位名和状态描述

**涉及文件**：`src/main/java/.../service/impl/ApplicationServiceImpl.java`

---

## 五、2026-06-02 修复记录

### 1. 职位发布草稿无法上线

**问题**：招聘方填完表单后职位以 DRAFT 创建，前端无发布按钮，无法发布到全部职位。

**修复**：

- `Jobs.vue`："我的职位"草稿旁加绿色"发布"按钮

### 2. 私信实时消息不显示 + 删除私聊

**问题**：
- WebSocket 发送后消息不浮现在聊天区（需刷新）
- 接收方也收不到实时推送
- 读完消息后角标无法消除

**根因与修复**：
- `Messages.vue`：WebSocket 发送后乐观更新本地消息数组；回调注册移到 `connect()` 前防止竞态
- `WebSocketConfig.java`：`/user` 从 `enableSimpleBroker` 移除（改为 `/queue`），修复 `UserDestinationMessageHandler` 被绕过导致 `convertAndSendToUser` 推送无法路由
- `useStomp.js`：WebSocket URL 加 `?token=` 参数，确保握手阶段建立 Principal
- `MessageServiceImpl.markAllReadFromPeer()` + `markRead()`：同步清除关联通知
- `Messages.vue`："全部已读"按钮 + 删除对话按钮

### 3. 职位详情空链接

**问题**：职位搜索点击职位跳转到 `/jobs/{id}`，但路由和页面都不存在。

**修复**：

- `main.js`：新增路由 `/jobs/:id`

### 4. 招聘方无法查看求职者简历

**问题**：`ResumeController` 的 `getLoginUserId()` 限制仅求职者可访问。

**修复**：

- `ResumeController`：新增 `GET /api/resumes/{id}/view` 端点（仅 RECRUITER/ADMIN）
- `RecruiterApplications.vue`：新增"查看简历"按钮 + 显示昵称/简历标题
