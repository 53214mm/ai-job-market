> 适用系统：Ubuntu 20.04+ / CentOS 7+ / Debian 11+

---

## 二、安装 Docker 环境

### 2.1 安装 Docker

```bash
# Ubuntu / Debian
curl -fsSL https://get.docker.com | bash
sudo usermod -aG docker $USER
newgrp docker

# 验证
docker --version
```

### 2.2 安装 Docker Compose

```bash
sudo apt install docker-compose-plugin -y
# 或
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# 验证
docker compose version
```

## 三、部署步骤

### 3.1 拉取项目代码

```bash
cd /opt
git clone <your-repo-url> ai-job-market
cd ai-job-market
```

### 3.2 配置环境变量

```bash
# 复制环境变量模板
cp .env.example .env

# 编辑 .env 文件，填入实际值
vim .env
```

**必须修改的项**：

| 变量 | 说明 |
|------|------|
| `MYSQL_PASSWORD` | MySQL root 密码 |
| `PG_PASSWORD` | PostgreSQL 密码 |
| `REDIS_PASSWORD` | Redis 密码 |
| `JWT_SECRET` | JWT 签名密钥（生成：`openssl rand -base64 32`） |
| `DASHSCOPE_API_KEY` | 阿里云 DashScope API Key |
| `APP_CORS_ORIGINS` | 服务器域名或 IP（如 `http://123.45.67.89,https://your-domain.com`） |

### 3.3 构建前端

```bash
cd ai-job-market-frontend
npm ci
npm run build
# 产出在 dist/ 目录
cd ..
```

### 3.4 构建后端

```bash
# 打包 jar（跳过测试）
mvn package -DskipTests
# 产出在 target/ai-job-market-0.0.1-SNAPSHOT.jar
```

### 3.5 启动所有服务

```bash
# 启动（后台运行）
docker compose up -d

# 查看日志
docker compose logs -f

# 查看服务状态
docker compose ps
```

### 3.6 验证部署

```bash
# 测试 API
curl http://localhost:8123/api/jobs?current=1&pageSize=5

# 测试 Nginx 静态文件
curl http://localhost/

# 浏览器访问
# http://<你的服务器IP>
```

## 四、防火墙配置

```bash
# 开放 HTTP 端口
sudo ufw allow 80/tcp

# 如需 HTTPS
sudo ufw allow 443/tcp

# 查看状态
sudo ufw status
```

**云服务器还需在控制台安全组中放行 80 端口。**

## 五、HTTPS 配置（推荐）

### 5.1 使用 Certbot + Let's Encrypt

```bash
# 安装 certbot
sudo apt install certbot python3-certbot-nginx -y

# 修改 nginx.conf 中的 server_name 为实际域名
vim nginx.conf
# server_name your-domain.com;

# 获取证书
sudo certbot --nginx -d your-domain.com

# 自动续期
sudo certbot renew --dry-run
```

## 六、常用运维命令

### 6.1 服务管理

```bash
# 重建并启动特定服务
docker compose up -d --build backend

# 重启服务
docker compose restart backend

# 停止所有服务
docker compose down

# 停止并删除数据卷（危险！）
docker compose down -v
```

### 6.2 查看日志

```bash
# 所有服务日志
docker compose logs -f --tail=100

# 仅后端日志
docker compose logs -f backend
```

### 6.3 数据库备份

```bash
# MySQL 备份
docker exec ajm-mysql mysqldump -u root -p ai_job_market > backup_$(date +%Y%m%d).sql

# PostgreSQL 备份
docker exec ajm-postgres pg_dump -U root ai_job_market > pg_backup_$(date +%Y%m%d).sql
```

### 6.4 更新部署

```bash
git pull
cd ai-job-market-frontend && npm ci && npm run build && cd ..
mvn package -DskipTests
docker compose up -d --build backend
```

## 八、故障排查

### 8.1 服务无法启动

```bash
# 查看具体错误
docker compose logs backend | tail -50

# 常见原因：
# - .env 文件未配置或变量名错误
# - 数据库连接失败 → 检查 MYSQL_HOST 等变量
# - 端口被占用 → 修改 HTTP_PORT
```

### 8.2 私信推送不工作

```bash
# 检查 WebSocket 连接
# 浏览器 F12 → Network → WS → 查看 /api/ws 连接状态
# 确认 nginx 配置中 WebSocket 代理头已设置
# 确认 .env 中 APP_CORS_ORIGINS 包含了当前访问域名
```

### 8.3 AI 功能不可用

- 确认 `DASHSCOPE_API_KEY` 在 `.env` 中已配置
- 确认 PostgreSQL pgvector 容器正常运行
- 查看后端日志 `docker compose logs backend | grep -i error`

### 8.4 邮件验证码发不出

- 确认 `MAIL_USERNAME` 和 `MAIL_PASSWORD`（QQ 邮箱授权码）已配置
- QQ 邮箱需要开启 SMTP 服务并获取授权码

## 九、生产环境建议

1. **JWT 密钥** — 使用 `openssl rand -base64 64` 生成强随机密钥
2. **数据库密码** — 不要使用默认密码，定期更换
3. **自动备份** — 设置 cron job 每日备份数据库
4. **日志轮转** — 配置 Docker 日志驱动 `max-size` 和 `max-file`
5. **监控** — 建议接入 Prometheus + Grafana 或阿里云监控
6. **HTTPS** — 生产环境必须使用 HTTPS
7. **防火墙** — 关闭不必要的端口，MySQL/Redis/PG 端口不对外开放
