> 最后更新：2026-06-02

## 一、项目简介

**AI Job Market（AI 智能招聘市场）** 是一个基于 Spring Boot + Vue 3 的全栈 Web 应用，面向求职者和招聘方提供智能化的招聘服务。系统集成了 AI 大语言模型（通义千问 Qwen-Max）、RAG 知识增强检索、pgvector 向量语义搜索、WebSocket 实时消息推送等技术，实现了从职位发布、简历投递、AI 匹配分析到面试安排、站内私信的完整招聘闭环。

### 技术栈

| 层级 | 技术 |
|------|------|
| **后端框架** | Spring Boot 3.5.2 |
| **ORM** | MyBatis-Plus 3.5.9 |
| **数据库** | MySQL 5.7+（主库）、PostgreSQL + pgvector（向量库） |
| **缓存** | Redis（对话记忆 + 验证码） |
| **AI 平台** | Spring AI 1.1.2 + 阿里云 DashScope（Qwen-Max / 1024 维 Embedding） |
| **消息推送** | STOMP over WebSocket（@stomp/stompjs + Spring Simple Broker） |
| **前端框架** | Vue 3（Composition API）+ Vue Router 4 + Tailwind CSS 4 + Vite 8 |
| **安全** | Spring Security + JWT 无状态认证 |
| **API 文档** | Knife4j + SpringDoc OpenAPI |
| **PDF** | iText Core 9.1 |
| **邮件** | Spring Boot Mail + QQ SMTP |
| **构建工具** | Maven + Vite |

## 四、核心功能模块

### 4.1 用户模块

- 邮箱注册（验证码）、JWT 登录
- 求职者/招聘方双角色
- 管理员用户管理（列表、搜索、禁用/解禁）
- 密码 BCrypt 加密存储

### 4.2 职位模块

- 招聘方发布/编辑/关闭/发布职位（草稿 → 已发布流程）
- 多条件搜索（关键词、城市、类别、薪资）
- **AI 语义搜索**：基于 pgvector 的 1024 维 Embedding 向量相似度搜索
- 职位向量化：发布时自动通过 DashScope Embedding API 向量化
- 管理员下架/上架任意职位

### 4.3 简历模块

- 在线创建/编辑简历（基本信息、教育、工作、项目、技能、证书）
- PDF 上传自动解析
- PDF 导出
- AI 简历分析和优化（评分、优点、建议）
- 隐私控制（公开/私有）
- 招聘方可查看投递到己方职位的简历

### 4.4 投递模块

- 求职者投递职位（含附言）
- 招聘方查看收到的简历
- 状态流转：已投递 → 已查看 → 筛选中 → 面试中 → Offer → 已录用/已拒绝
- 撤回投递
- 状态变更自动推送通知

### 4.5 消息与通知

- **WebSocket 实时推送**（STOMP over WebSocket）
- 站内私信：实时发送/接收，已读/未读状态
- 会话管理：列表、搜索、删除
- 系统通知：投递状态变更、面试邀请等
- 未读角标实时更新（通知 + 私信分离计）

### 4.6 AI 模块

- **AI 聊天助手**：基于 Qwen-Max 的对话，支持 RAG 知识增强，SSE 流式输出
- **AI 简历分析**：自动评分（综合/格式/内容/关键词）+ 优缺点 + 改进建议
- **AI 简历优化**：对简历内容进行 AI 驱动的改写和优化
- **AI 职位-简历匹配**：基于技能关键词计算匹配分数
- **AI 面试模拟**：模拟面试场景

### 4.7 公司模块

- 招聘方创建/编辑公司信息
- 公司详情公开浏览
- 公司评价系统（评分、优/缺点）

### 4.8 内容管理

- 管理员发布文章（求职攻略、行业资讯）
- 文章分类管理
- 求职者/招聘方可浏览文章列表和详情

### 4.9 系统运维

- Swagger/Knife4j API 文档
- CORS 跨域配置
- 全局异常处理
- MyBatis-Plus 自动填充（创建/更新时间）

## 六、AI 架构详解

### RAG（检索增强生成）流程

```
用户提问 → QueryRewriter 改写查询 → PgVectorStore 向量检索 TOP-N 文档
         → DocumentAugmenter 增强上下文 → Qwen-Max 生成回答（SSE 流式返回）
```

### 职位语义搜索流程

```
职位发布 → 拼接 title+description+skills → DashScope Embedding API（1024 维）
         → JDBC 直写 job_vectors 表
用户搜索 → Embedding API 向量化查询 → pgvector 余弦相似度检索 TOP-N
         → 解析 metadata 提取 jobId → MySQL 查询完整职位数据 → 返回排序结果
```

### Agent 智能体架构

```
用户请求 → BaseAgent → ReActAgent（推理-行动循环）
         → ToolCallAgent → 调用工具（搜索/文件/PDF/终端/网页抓取）
         → JobAgent → 返回最终结果
```
